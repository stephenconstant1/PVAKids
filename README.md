# Financial Freedom: Money Ops — Prototype 0.1
Open index.html in a browser.

Current playable loop:
Mission Briefing → Lesson → Financial Decision → Unexpected Event → Consequence → Debrief → Replay.

Mission 01 teaches budgeting and emergency savings. The visual direction is an original cinematic tactical interface; gameplay remains simple enough for a middle-school learning game.

Next: persistent profiles/ranks, mission map, budgeting, credit, investing/compound growth, entrepreneurship, teacher/classroom mode, audio and original cinematic graphics.
