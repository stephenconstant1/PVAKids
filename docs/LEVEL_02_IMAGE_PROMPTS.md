## New image requests

Prepend this style direction to each prompt: **Create original transparent PNG artwork for CMI Money Ops Project℠. Match the existing bright illustrated Moneybread City style: warm lighting, clean dark outlines, rounded shapes, gentle shading and clear silhouettes. Prefer 1024×1024, with 12% transparent padding. Keep it recognizable at 32–64 pixels. No logos, watermarks, embedded prices, percentage returns, UI buttons or guaranteed-growth arrows. Words and changing balances will be rendered separately.**
